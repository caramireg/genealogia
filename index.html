Reglas de la Notación Jerárquica

Cómo asignar los códigos de nivel a los ancestros y descendientes

1. Patriarca o Matriarca (Tronco Raíz):
Usa números enteros seguidos de punto (ej. 1., 2.).

2. Hijos (Primera Generación):
Agrega un punto y un número ordinal según el nacimiento (ej. 1.1. es el primer hijo de 1.; 1.2. es el segundo hijo).

3. Nietos y Bisnietos:
Continúa añadiendo niveles (ej. 1.1.1. es el primer hijo de 1.1.).

Ejemplo de Texto Válido:
1. Don Juan José Gómez, n. 1780. Casado con Rosa Acevedo.
1.1. Lino Gómez Acevedo, b. 1802. Casado con Eduvigis Gómez.
1.1.1. Pedro Gómez Acevedo, comerciante.
1.1.2. María Ignacia Gómez Acevedo, c.c. Manuel Toro.
1.2. Antonio Gómez Acevedo, f. 1860.

Separación Automática de Nombres y Biografías

El algoritmo distingue automáticamente la identidad de la persona de sus datos adicionales

Para asegurar que el nombre aparezca limpio en los nodos del árbol y los detalles biográficos en la ficha lateral, el sistema busca separadores clave:

1. Por Coma ( , )

Todo lo previo a la primera coma es el nombre. Todo lo posterior pasa a la biografía.

2. Palabras Clave

Palabras como casado, casada, nació, bautizado o fallecido actúan como separador natural.

3. Títulos Honoríficos

Expresiones como Don, Doña, Pbro. o Dr. se conservan respetuosamente en el nombre.

Guía de Formatos de Exportación

Cuándo utilizar cada uno de los formatos disponibles

Formato Extensión Uso Principal Recomendado
🖼️ Imagen PNG .png Para insertar en documentos de Word, trabajos escolares, presentaciones PowerPoint o redes sociales. Renderiza en alta calidad.
✂️ PNG/SVG por Recorte .png / .svg Permite dibujar un rectángulo con el ratón sobre el área del árbol que deseas mostrar para exportar únicamente dicha sección.
📐 Vectorial SVG .svg Para impresiones profesionales de gran tamaño (cuadros, carteles, plotters) sin pérdida de nitidez o para diseñar en Illustrator/Figma.
🌐 HTML Interactivo .html ¡El mejor para enviar a familiares! Genera un archivo autónomo con el árbol dinámico que funciona en cualquier celular o PC sin internet.
📜 GEDCOM .ged Estándar mundial para importar tu árbol a software especializado como Ancestry, FamilySearch, MyHeritage o Gramps.
📦 Estructura JSON .json Para guardar copias de respaldo de tus datos y poder abrirlos de nuevo en GeneaPro más adelante.
